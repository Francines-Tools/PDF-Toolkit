Analyzing…

Text, fonts and vector graphics stay untouched. Only embedded images are downsampled and re-encoded as JPEG. Estimates are approximate; the real result is shown when done.

Items are a draft on top of the pages until you tap Apply, which adds them to the PDF in memory. Apply doesn’t create a file; Save PDF does. Tap an item to select it: drag its Move tab to reposition and the round corner handle to resize. Mono box: stretch it over a form field; letters spread evenly across the width. Set character cells to match the field’s number of squares.

Some pages are rotated; items on them can’t be exported accurately.

Drag on the page to select an area, then extract it. PNG is a picture of the area. A cropped PDF keeps vectors and text, but the rest of the page is still inside the file, so don’t use it to hide information.

Tap text on the page to select it. Each box is one piece of text as stored in the file. Edited text uses the original font when it contains every character you typed, otherwise a standard font (the dropdown). Deleted text is removed from the page. Text inside images can’t be edited.
